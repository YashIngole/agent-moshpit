# Agent Moshpit v0.5.0

- **Local voice input.** Optional CPU recognition, off until enabled. Explicitly download multilingual Small Q5_1 (190.1 MB) or lighter Base Q5_1 (59.7 MB) from Hugging Face, outside the installer. Audio and transcription stay local. Text goes into the selected live terminal for you to review and send; Moshpit never presses Enter. Recordings are bounded to 60 seconds and cancelled when their terminal or window goes away.
- **Agent launch settings.** Choose Claude Code or Codex model, effort, permissions and advanced options in **New agent**. Leave settings on **Use CLI settings** to inherit your program's configuration. Overrides survive restart and **Start another like this**; CLI configuration files are not edited.
- **Live model catalogs.** Refresh model and effort choices from your installed CLI without an app update. Requests share a bounded cache, have time/output limits, and send no task or model inference request. Custom model IDs remain available when discovery fails.
- **Internal session coordination.** Claude Code and Codex receive a local MCP connection to discover sessions, delegate tasks, check an inbox and retrieve explicit results. Native CLI worktrees are supported. Connections have separate session capabilities, expire when programs stop, and enforce project scope and bounded delegation. Prompts and results are saved locally in `coordination.json`.
- **Editable agent labels.** Agents can name an unnamed desk and describe their current activity. Names you supplied stay protected, and observed approval prompts take priority. Existing-session tasks wait in the MCP inbox; Moshpit does not type into another terminal or answer its approval prompts.
- **Session and desktop reliability.** Preserve unreadable saved offices, verify CLI resume IDs, keep same-name projects separate, and refuse to restart in missing folders. The Windows speech engine uses a static C++ runtime.

Voice microphone permissions, device routing, accent quality and Hindi/Hinglish quality remain manual checks; see the [voice validation record](https://github.com/YashIngole/agent-moshpit/blob/main/docs/reviews/voice-validation-2026-10-09.md). Coordination is tested with stand-in Claude/Codex agents and the real stdio bridge; live model delegation is not part of automated verification. See the [internal MCP guide](https://github.com/YashIngole/agent-moshpit/blob/main/docs/internal-mcp.md) for tools and limits.

Update from **More** or use the installers below. Windows and macOS retain the existing [code-signing limitations](https://github.com/YashIngole/agent-moshpit#install). The v0.4.0 tag failed its release gates and was never published; v0.4.1 was superseded before tagging by this combined release.

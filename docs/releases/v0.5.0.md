# Agent Moshpit v0.5.0

Choose how Claude Code and Codex start from **New agent**: model, effort, permissions and optional advanced settings. Leave any setting on **Use CLI settings** to inherit your program's configuration.

- **Live model pickers.** Models and supported effort levels come from your installed CLI's catalog. Refresh finds new releases without an Agent Moshpit update; an open picker refreshes every 15 minutes. Custom model IDs remain available if discovery fails or your CLI does not expose a catalog.
- **Provider permissions.** Claude offers its installed permission modes, including Auto and bypass permissions when supported. Codex offers workspace and read-only sandboxes, automatic approval review, YOLO/full access, and separate sandbox/approval controls.
- **Advanced settings.** Additional folders, Codex profiles and web search, and Claude tool rules, Chrome integration and extra instructions. Overrides belong to the desk and survive agent restart, app restart and **Start another like this**. CLI configuration files are not edited.
- **Bounded discovery.** Catalog requests share a cache, coalesce concurrent probes and have time/output limits and process cleanup. Discovery sends no agent task or model inference request.

This release also includes changes already on main since v0.3.0: optional local voice input and session/persistence reliability fixes. Voice is off until enabled, uses explicitly downloaded local recognition models, and inserts text for you to review and send. Audio stays local. Accent and Hindi/Hinglish recognition quality remains unmeasured; see [voice validation](https://github.com/YashIngole/agent-moshpit/blob/main/docs/reviews/voice-validation-2026-10-09.md).

Update from the app's **More** menu or use the installers below. Windows and macOS installers retain the existing code-signing limitations described in the [installation guide](https://github.com/YashIngole/agent-moshpit#install).

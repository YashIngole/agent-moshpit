# Agent Moshpit v0.5.1

This patch improves the office UI while retaining v0.5.0's voice input, internal MCP and agent launch settings.

- **More trustworthy status.** A program that stops printing shows **Quiet** until completion is confirmed. Quiet programs still ask before Stop, Restart, Remove or Quit.
- **Clear resume targets.** **Carry on** resumes a saved desk session. **Continue in folder** and **Continue latest** explain when a program may select another desk's conversation.
- **Attention stays visible.** Waiting agents remain on the amber band until answered. Covered or unselected terminals are no longer treated as read. Narrow windows retain names and keyboard-accessible status actions.
- **Visible form recovery.** An empty Folder receives focus and an inline error. Start and Cancel sit outside the scrolling fields, keeping focused fields clear.
- **More terminal room.** Multiple laptop panes begin beside a compact floor, with a visible control to expand it. Crowded rooms fit side by side on larger windows and keep readable names on narrow ones.
- **Safer recovery.** Configuration warnings survive navigation and remain available after dismissal. Consecutive desk removals share **Undo all**, with expiry paused during hover or keyboard focus.
- **Readable controls.** Menus keep a visible keyboard focus outline, scroll within small windows and show full hints. Program commands wrap in full, Installed and Available programs are grouped, and the terminal cursor follows reduced motion.

The [fix record](https://github.com/YashIngole/agent-moshpit/blob/main/docs/reviews/ui-ux-2026-10-09/fixes/resolution.md) lists all 15 reviewed findings and their regression coverage. Resume targets are verified against adapter configuration; no real Antigravity/Hermes conversation or model task was used for automated checks.

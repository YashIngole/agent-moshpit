# Agent Moshpit v0.5.3

This patch repairs local voice input and makes setup, recording and recovery easier to follow.

- **Choose your microphone.** Voice settings list available inputs, show the system default and let you refresh after connecting a device. Recording shows which microphone is active.
- **See whether audio is arriving.** A live input meter and timer show recording progress. Silent input gets a useful hint; a stream that stops delivering samples fails with recovery instructions.
- **Better quiet-speech handling.** Sustained quiet recordings that previously failed the audio gate can reach transcription, with bounded amplification. Silence, short clips and isolated clicks still insert nothing.
- **Clear setup and downloads.** Voice stays accessible while disabled or missing a model. Setup offers a direct download of the selected model. Base is recommended for new settings; existing Small selections are preserved.
- **Understand the wait.** Transcription shows elapsed time and explains longer CPU processing. Errors offer retry and setup actions. Stop returns focus to the original terminal unless you moved elsewhere while waiting.

Audio remains local. Text goes into the terminal where recording began, without pressing Enter. Cancel and window close discard pending results.

The [repair record](https://github.com/YashIngole/agent-moshpit/blob/main/docs/reviews/voice-repair-2026-10-10.md) includes browser, native setup and recorded-audio checks. Live capture with the reporter's physical microphone remains unverified.

Update from **More** or use the installers below. Select your microphone under **More → Voice input**, then check that the input meter moves while speaking. The existing [code-signing limitations](https://github.com/YashIngole/agent-moshpit#install) remain.

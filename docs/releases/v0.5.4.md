# Agent Moshpit v0.5.4

This patch fixes problems found in a review of v0.4.0 to v0.5.3: voice downloads and dictation, a status that could stay "Quiet" for good, delegated sessions' permissions, and the release process.

- **Model downloads keep going.** Minimizing the window or closing it to the tray no longer cancels a voice model download. Only quitting the office does.
- **Dictate while another model downloads.** Recording with a model that is already in place no longer waits behind a download of the other one, which could leave it on "Transcribing" for minutes.
- **Faster repeat dictation.** The model is no longer read and checked in full before every recording, and stays loaded for five minutes after the last one, so the next one starts sooner.
- **Fewer invented words.** Speech must now stand out from the recording's own background, so steady room noise is rejected instead of being amplified, and passages the model rates as no speech are dropped. This is checked with synthetic audio; it reduces, but cannot rule out, words heard in noise.
- **Quiet ends.** A program that never sends a completion notice (every program except Claude Code, and Codex when it sends none) stayed **Quiet** after its first piece of work, and kept asking before Quit and Update. A full minute of silence now counts as finished.
- **Delegation never loosens permissions.** A session started through the internal MCP inherits its parent's launch settings, permissions and sandbox included. A parent with permission settings of its own can only start its own program, since settings cannot be translated between programs.
- **macOS voice after minimizing.** Voice comes back when the restored window is focused, not only when it is resized.
- **Windows install command.** `irm https://agentmoshpit.com/install.ps1 | iex` no longer leaves its error and progress settings behind in your PowerShell window.
- **Release safeguards.** A release is built only from a tag on `main` whose version matches the app's, and the release workflow's actions are pinned to exact commits.

Update from **More** or use the installers below. The existing [code-signing limitations](https://github.com/YashIngole/agent-moshpit#install) remain.

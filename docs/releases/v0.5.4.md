# Agent Moshpit v0.5.4

This patch fixes problems found in a review of v0.4.0 to v0.5.3: voice downloads and dictation, a status that could stay "Quiet" for good, delegated sessions' permissions, the install commands and the release process.

- **Signed install commands.** `install.sh` and `install.ps1` now check, before anything is unpacked or run, that the release's list of installer hashes is signed with a key pinned in the scripts, and that the download has the hash the list gives it. A missing or wrong signature, or a changed file, installs nothing. The check uses `ssh-keygen` from the OpenSSH that macOS, Linux desktops and Windows 10 and 11 include.
- **Delegation stays within one program.** A session started through the internal MCP is always the same program as the one that asked, from the same harness row and configuration, with its launch settings and permissions. Codex can no longer start Claude Code, or the other way round: their permission settings cannot be compared, so another program could have run with broader ones.
- **Short dictation works, and noise inserts nothing.** Speech no longer needs pauses around it to be accepted. Steady hiss and hum are rejected before recognition, and the notes the model writes for other noise, such as `[BLANK_AUDIO]` or `[APPLAUSE]`, are no longer inserted into the terminal as text.
- **Model downloads keep going.** Minimizing the window or closing it to the tray no longer cancels a voice model download. Only quitting the office does.
- **Dictate while another model downloads.** Recording with a model that is already in place no longer waits behind a download of the other one, which could leave it on "Transcribing" for minutes.
- **Faster repeat dictation.** The model is no longer read and checked in full before every recording, and stays loaded for five minutes after the last one.
- **Quiet ends.** A program that never sends a completion notice (every program except Claude Code, and Codex when it sends none) stayed **Quiet** after its first piece of work, and kept asking before Quit and Update. A full minute of silence now counts as finished.
- **macOS voice after minimizing.** Voice comes back when the restored window is focused, not only when it is resized.
- **Windows install command.** `irm https://agentmoshpit.com/install.ps1 | iex` no longer leaves its error and progress settings behind in your PowerShell window.
- **Release safeguards.** A release is built only from a tag on `main` whose version matches the app's, and the workflows' actions are pinned to exact commits.

Voice was checked with recorded speech and synthetic noise, not with a live microphone in a noisy room. Update from **More** or use the installers below. The existing [code-signing limitations](https://github.com/YashIngole/agent-moshpit#install) remain.

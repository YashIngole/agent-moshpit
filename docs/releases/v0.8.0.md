# Agent Moshpit v0.8.0

Arrange your terminals any way you like, see whether one agent's message reached another, and sign in to a program without leaving the office.

## Arrange your terminals

- **A pane goes where you drop it.** Drag a terminal by its header onto another: drop on a side and it goes there, drop in the middle or on the header and the two change places, drop at the edge of the room and it takes that whole side. A blue outline shows where it will land before you let go, and `Esc` puts it back.
- **Arrange them all at once.** With two or more terminals open, **arrange** in the bar lays them out in a grid, side by side, stacked, or with one large and the others beside or below it. The notice that follows has **Undo**.
- **By keyboard.** `Ctrl+Shift` and an arrow moves to the pane on that side; add `Alt` and the pane itself moves that way.
- **Carry on draws properly.** A program carried on in a pane is started at that pane's real size. It no longer comes back garbled until the window is resized.

Layouts saved by 0.7.0 are kept.

## Agents can message each other, and you can see it arrive

- **Messages, not only tasks.** Ask a Claude Code or Codex agent to send its findings to the agent at another desk, or to start another session for a review. A message goes through the office to the other agent's inbox. Nothing is ever typed into a terminal, and nothing answers a permission question for you.
- **You can see how far each one got.** **⋯ → Agent messages** lists what was sent and, for each, whether it was saved, told to the agent (and how), read in full, and acknowledged. Each step claims only what the office knows. Acknowledged is a receipt: the agent saying it arrived, not agreeing to do anything.
- **Claude Code is told while it works.** A Claude Code agent now hears of a message at the next step of its work, and once more as its turn ends if it still has not read it. An agent sitting idle at its prompt is woken for it. That turn uses your tokens, so **Wake it when it is idle** can be turned off in the same panel; then it hears with your next prompt.
- **Pushed in as it arrives, if you turn it on.** The panel can also start Claude Code with its Channels research preview, which pushes a message into the session the moment it is sent. It is off by default: Claude Code asks you to confirm in the terminal each time such a session starts, and in our trials a message that was only pushed was read but not acknowledged. Leave the first choice on beside it.
- **Codex** has no such way yet. A Codex agent finds what is new with its next call to the office, or when it checks its inbox; an idle one waits for your next prompt.
- **Sent while an agent is stopped,** a message is kept and told when the agent is carried on.

These apply to sessions started or carried on after you change them. [How it works, and its limits](https://github.com/YashIngole/agent-moshpit/blob/main/docs/internal-mcp.md).

## Signing in and out

- **Who is signed in.** **⋯ → Agent programs** shows who is signed in to Claude Code and Codex, in the program's own words, with a button to **sign in** or **switch account**. The program's own command runs in a pane and opens your browser.
- **A signed-out desk says so.** When a program ends because it was signed out, its pane says that and offers **Sign in**, instead of only "Their program is not running".

One account at a time for each program. Desks already running keep their sign-in until they are restarted.

## New agent

- **Say the task.** A microphone beside "What should they do?" types your words into the task as you speak, where the caret is. `Ctrl+Shift+Space` does the same while the form is open.
- **Plugins for one desk.** Advanced launch settings lists the plugins your Claude Code has, each with a tick box. On or off for that desk only; your Claude Code settings stay as they are.
- **Extra arguments.** One field for anything else you would type after `claude` or `codex`, passed each time that desk starts or carries on.
- **A program installed while the office is open is found without restarting it,** Node.js included. On a computer without Node.js, the form and the Programs panel say so before you press anything, with a button to get it.
- **A desk nobody named** takes its name from what Claude Code or Codex calls the conversation, after the first prompt. A name you give always wins.

## Voice

- **OpenRouter.** Cloud voice takes an OpenRouter key as well, using ElevenLabs Scribe v2. OpenRouter has no live stream, so your words arrive a phrase at a time, at each pause.

## Fixed

- **Start** pressed while dictating a task, then cancelled, no longer starts an agent anyway.
- A pane inside a nested arrangement can no longer be dragged too small to read.
- A desk that finished while you were not looking no longer keeps showing what it said it was doing before.
- Claude Code no longer stops to ask before naming its own desk or reading its own inbox.

## The website

- The home page and guides were rewritten to say each thing once, and open on the app itself.
- The download buttons now count how often each installer is asked for, with Cloudflare. One number is kept for each day, file, way it was asked for and country: nothing about who asked, and no cookie.

Arranging, the New agent form, sign-in and messages were checked in the real Windows app with stand-in programs, and message delivery again with the real Claude Code 2.1.296 on its smallest model: busy, idle, stopped and carried on, and stopped on a permission question, one trial of each. With the real Codex 0.162.1 a message was read and acknowledged in one trial and read past in another, where the prompt said to do only one thing. None of this was checked with other models or long conversations. Signing out of the real programs was not tried, because it would sign every open session out. Voice through OpenRouter was checked against a pretend provider, not with a real key, and saying a task with demo audio, not a live microphone. Nothing here was used by hand on macOS or Linux. If something misbehaves, please [open an issue](https://github.com/YashIngole/agent-moshpit/issues). Every known gap is in [limits.md](https://github.com/YashIngole/agent-moshpit/blob/main/docs/limits.md). Update from **⋯** or use the installers below. The existing [code-signing limitations](https://github.com/YashIngole/agent-moshpit#install) remain.

pty-proof, 2026-10-08, Windows 11 (10.0.26300), Claude Code 2.1.290, Codex 0.160.0, portable-pty 0.9.0

The question: can one windowed app run Claude Code and Codex as its own children, each in a
pseudo-terminal, without any of them getting a window (and so a taskbar button) of its own?

The answer: yes.

  check.ps1 -Commands "C:\Users\Yash\.local\bin\claude.exe","cmd.exe /d /c codex" -Hold 14
